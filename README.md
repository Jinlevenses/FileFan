# FileFan

파일을 드래그하며 변환하고, 화면 가장자리의 선반에 모아 두는 macOS 메뉴 막대 앱입니다. AppKit과 SwiftUI로 만들었으며 파일 관리와 변환은 로컬에서 처리합니다.

## 주요 기능

- **드래그 휠**: 파일을 드래그하면서 Shift를 탭하면 변환, Command는 파일 종류별 도구, Control은 공통 파일 액션을 엽니다. 키를 놓아도 휠을 유지하며 구역에 파일을 직접 드롭합니다. Escape나 드래그 종료로 닫습니다.
- **파일 선반**: 파일·폴더 추가, 다중 선택, Quick Look, Finder에서 보기, 경로 복사, 외부 드래그를 제공합니다.
- **가장자리 도킹**: 선반을 화면 가장자리로 옮겨 붙이고 핸들로 다시 엽니다. 메뉴나 Command+Option+방향키로도 도킹하고 Command+Option+U로 해제합니다.
- **재실행 복원**: 선반 항목·선택·창 위치·도킹 상태·변환 설정을 저장합니다. 없어진 파일은 별도로 표시해 다시 찾거나 참조만 제거할 수 있습니다.
- **로컬 변환**: 이미지·PDF·문서·한글·미디어 등 17개 형식군을 다룹니다. 실제 실행 가능한 형식은 변환 엔진과 입력 조합에 따라 결정하며, 사용할 수 없는 항목에는 이유를 표시합니다.

선반에서 항목을 제거해도 원본 파일은 삭제하지 않습니다. 변환은 출력 폴더에 새 파일을 만들며 이름이 충돌하면 기존 파일을 보존합니다. **Move** 액션을 명시적으로 선택하면 원본 위치가 이동합니다.

## 사용 방법

1. 메뉴 막대에서 선반을 열고 파일을 추가하거나 Finder에서 파일을 드래그합니다.
2. 드래그 중 modifier 키로 휠을 열거나 선반의 **All Formats…**, **Tools for Selected Files**, **Actions**를 사용합니다.
3. 형식 또는 도구를 고르고 출력 폴더와 옵션을 설정합니다.
4. 파일별 결과를 확인합니다. 선택이 없으면 선반 전체를 사용합니다.

변환 목록은 선택한 파일과 같은 종류를 먼저 보여 줍니다. 같은 종류의 형식은 여러 줄 버튼으로 함께 표시하며 검색·품질·최대 이미지 크기·PDF 페이지 범위를 설정할 수 있습니다. 혼합 선택에는 모든 입력에 적용 가능한 경로만 활성화합니다.

## 파일 도구

| 종류 | 도구 |
|---|---|
| 이미지 | 압축, 메타데이터, 편집, 주석, 배경 추가, 자르기, 가리기 |
| 동영상 | 압축, 메타데이터, 음소거, 구간 추출, 자르기, 속도, 스냅샷, 가리기, 분할 |
| 오디오 | 압축, 메타데이터, 구간 추출, 속도 |
| PDF | 압축, 메타데이터, 합치기, 분할, 페이지 추출, 주석 |
| 문서·한글·텍스트 | PDF, 텍스트, 편집, 메타데이터 |
| 스프레드시트·프레젠테이션 | PDF·CSV·XLSX 또는 PDF·PPTX·PNG, 메타데이터 |
| 압축·자막·JSON | 압축 해제·ZIP 생성, 자막 형식 변환, JSON 검사·정리 |
| 모든 파일 | AirDrop, Float, Copy, Move, Copy Path, Terminal |

이미지 편집은 첫 프레임을 새 PNG로 저장합니다. 이미지 압축은 투명 배경을 흰색으로 바꾸는 JPEG 저장이며 크기 감소를 보장하지 않습니다. 동영상·오디오 편집은 새 MP4(H.264/AAC)·M4A(AAC), 스냅샷은 PNG로 저장합니다. 문서 편집과 PDF 주석은 복사본을 시스템 편집기로 엽니다.

## 변환 범위

이미지, 벡터, PDF, 문서, 스프레드시트, 프레젠테이션, HWP/HWPX, 텍스트·마크업, 전자책, 동영상, 오디오, 자막, 압축, CAD, 글꼴, 데이터, 3D 모델을 분류합니다. 카탈로그 목록과 실제 변환 가능 여부는 구분합니다. 모든 형식 간의 상호 변환을 보장하지 않습니다.

PNG/JPEG는 시스템 ImageIO 경로를 사용할 수 있습니다. 광범위 변환에는 별도의 CLI backend와 형식별 엔진이 필요합니다. PDF 압축·페이지 작업, 이미지 크기 변경, 미디어 처리와 압축 해제도 입력 및 엔진 상태에 따라 제공됩니다.

## 개발 및 빌드

Swift 앱의 빌드 대상은 macOS 13 이상입니다. 광범위 변환 backend의 .NET 10 지원 대상은 macOS 14 이상이며 현재 번들 경로는 Apple Silicon용입니다. 개발에는 Swift 도구 체인과 Python 3가 필요하고 전체 앱 패키징에는 .NET 10 SDK와 고정 backend 입력도 필요합니다.

```sh
zsh scripts/test.sh
swift build -c release --product FileFan
```

backend 입력을 준비한 후 앱 번들을 만듭니다.

```sh
zsh scripts/build-app.sh
open dist/FileFan.app
```

준비 경로는 [빌드 안내](docs/BUILDING.md), 시험 범위는 [검증 안내](docs/TESTING.md)에 있습니다. 이 저장소는 소스와 빌드 스크립트를 제공하며 실행 파일·변환 엔진·개발 데이터는 포함하지 않습니다. 생성한 앱은 로컬 ad-hoc 서명이며 Developer ID 공증 배포판은 아닙니다.

## 데이터 저장

선반 상태는 기본적으로 `~/Library/Application Support/FileFan/session.json`에 저장합니다. 개발·시험에서는 `FILEFAN_DATA_DIR`로 별도의 저장 디렉터리를 지정할 수 있습니다. 변환 작업도 전용 디렉터리를 사용합니다.
